Что такое GameGuard?
GameGuard — это программа для Windows, которая помогает контролировать игровое время. Вы устанавливаете лимит (например, 30 минут), а после его истечения программа принудительно закрывает игры, устраивает «цифровой хаос» (двигает мышку, открывает окна) и блокирует запуск игр до следующего дня. Это не просто таймер, а психологический инструмент, который формирует негативную ассоциацию с играми.

Как это работает?
Установка лимита. При запуске вы вводите количество минут.

Слежение. Программа сканирует процессы и закрывает игры (Roblox, CS:GO, Minecraft, Valorant и др.), если они запущены.

Истечение времени. Игры закрываются, начинается хаос (движение мыши, нажатие клавиш), и устанавливается бан до полуночи.

Самоуничтожение. По желанию программа может удалить себя, но оставить файл с датой бана.

Автозагрузка. Программа добавляет себя в автозагрузку и защищает от удаления.

Для кого?

Для людей которые хотят бросить, но не могут

Для того чтобы не отвлекаться 

Психологическая основа
Современные игры вызывают дофаминовую зависимость: мозг привыкает к наградам (уровни, достижения) и требует их снова. GameGuard использует метод отрицательного подкрепления — вместо напоминаний она создаёт дискомфорт, заставляя мозг ассоциировать игры с негативом. Это помогает разорвать «петлю зависимости»: триггер → игра → награда.

What is GameGuard?
GameGuard is a Windows program designed to help you control your gaming time. You set a time limit (e.g., 30 minutes), and once it expires, the program forcefully closes games, triggers "digital chaos" (moving the mouse, opening windows), and blocks game launches until the next day. This is not just a timer — it's a psychological tool that builds a negative association with gaming.

How It Works?
Setting a limit. When you launch the program, you enter the number of minutes you want to play.

Monitoring. The program scans for running processes and closes games (Roblox, CS:GO, Minecraft, Valorant, and others) if they are active.

Time's up. Games are closed, chaos begins (mouse movements, key presses), and a ban is set until midnight.

Self-destruction. Optionally, the program can delete itself but keep the ban date file.

Startup protection. The program adds itself to Windows startup and protects against removal.

Who Is This For?
For gamers who want to reduce their gaming time.

For people who want to quit but can't.

For staying focused and avoiding distractions.

Psychological Basis
Modern games create dopamine addiction: the brain gets used to rewards (levels, achievements) and craves more. GameGuard uses negative reinforcement — instead of reminders, it creates discomfort, making the brain associate games with negativity. This helps break the "addiction loop": trigger → gaming → reward.

Installation
Simply download the .exe file and run it.

Important
The program is free for personal use. You are responsible for your actions. Remember: your desire to change is what matters most — the program is just a helper on your journey.
